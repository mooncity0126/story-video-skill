分镜增强和相邻连续性约束：

把场景固定结构和人物以外的每件可见物品登记为 props 对象；不要只列剧情关键道具。
两个杯子等可以独立移动的物品必须有不同 prop_id。原料与容器分别登记，容器不能互换。
每个 prop 增加 basis 字符串，说明原剧本依据，或明确标注必要的制作设计建议。

每镜增加 objects 数组，包含该镜起始或结束可见的全部物品：
{"prop_id":"P1","start_visible":true,"end_visible":true,
 "start_state_id":"S1","end_state_id":"S1",
 "start_description":"精确数量、外观、位置、容器与物理状态",
 "end_description":"镜尾的相同维度描述",
 "entry_reason":"首次出现、从画外带入或机位揭示的依据",
 "exit_reason":"离画的方向、机位变化或移走动作；不离画可为空",
 "transition_reason":"与前一镜结束状态不同的明确原因；一致时为空"}

状态 ID 相同时描述也保持相同。镜内变化必须由该镜动作解释。
不在画中的对象不必列出；没有独立物品时，objects=[] 并给出 no_objects_reason。
focus_prop_ids 必须包含在 objects 中。人物不要在对象表重复登记。

连续性逐对检查：只比较第 N-1 镜的结束和第 N 镜的起始，不将更早镜头的可见物品强制带入。
前一镜已经离画的物品，下一镜允许不提及。仍在画的物品不能无故消失。
新入画的物品必须有已登记的身份与明确来源，不能因润色提示词添加额外物品。
明确场景切换允许旧空间物品离画；同场景的状态改变需写清过渡依据。
外观、身份、数量、容器、持有者、位置、破损、填充、烛火等都应逐项核对。

首帧只描绘动作开始前的一个时点。视频每镜一个主要动作，允许完成它所需的自然准备动作。
串行制作时，前镜真实尾帧负责最新物理状态，场景参考只负责固定布局。
若没有配置文本 API，这些内容由作者/Codex 明确整理为外部输入 JSON；不得声称调用了文本模型。
