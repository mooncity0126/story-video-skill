# 从分镜到最终视频提示词

用于原工作流节点 8。重点适配 `drama-skills/short-drama-video-prompts`，并按 [minimax-h3.md](minimax-h3.md) 输出当前接口可直接提交的 H3 正文。由当前 AI 结合实际素材写稿。本片默认建议直写，用户也可在[首次设置](first-use.md)选用本地改写或在线优化。仍沿用既有评审节点。

## 输入与上游依赖

上游技能分工是创作文档之间的依赖，本项目用已有产物承接，不要求额外安装整套技能：

| 上游职责 | 本项目提供的输入或执行环节 |
|---|---|
| `short-drama-write`：定稿剧本、台词与声音事实 | `script.md`、[story-writing.md](story-writing.md) |
| `short-drama-assets`：人物、造型、空间和声音设定 | `bible.json`、`reference-index.json`、实际设定图 |
| `short-drama-storyboard`：镜长、起止状态、机位、参考素材 | `storyboard.json`、[scene-planning.md](scene-planning.md)、`frames/Sxxx.json` |
| `short-drama`：项目模型与音画路线 | `settings.json`、本次接口规格；原生音画 `same_pass` |
| `short-drama-produce` / `short-drama-edit`：投产和剪辑 | 既有 `media_tools.py` 的提交、查询、检查及完整音轨合成 |

缺输入时补齐相应创作产物；发生矛盾时回到对应原节点修正，不能在提示词中悄悄改剧情、删台词、换说话人或延长时长。上游可用计划参考 `PLAN` 起草，本地投产仍必须绑定真实图片。当前接口没有参考音频字段，不接入上游的音色样本服务或后期配音路线。

## 三步写法

### 1. 明确生成模式与真实起点

读取本镜定稿、人物/场景锚点、实际首帧、可选目标尾帧及当前规格。看清画面中的姿态、视线、物品归属和起始构图，再写它们如何变化；这属于编写提示词的输入理解，不额外开启一轮 VLM 检查。

从节点 5 读取本镜的依赖决定。换机位、正反打、反应镜头都可能承接刚发生的动作、人物站位或物品变化。此时以来源视频经检查采用后的实际末帧、既定场景和人物参考编辑新机位的首帧。只共享外观且起始状态独立时，复用相应参考即可。首尾帧模式用于本镜另有明确约束的终点，正文仍写清动作如何到达该状态。

### 2. 把表演放进已确定的时间

沿用分镜的对白窗口、动作重叠关系、切点和最后一句后的余量，估时方法见整场规划文档。重要的接触动作交代接近、接触、施力/位移、落定；不把每个手部小动作都写成独立节拍。

若内容放不下，先删除无意义的小动作，再允许自然并行；仍不足则回到分镜延长/切分，或在已授权的写作范围内精简台词，并同步定稿。不能自行吞句、追加台词、要求超快语速或把话压到片尾。确有节拍需要才分时间段；分段时覆盖全片，不能遗漏片尾或安排矛盾的同时动作。

### 3. 写成一个可表演的动态过程

按“开场姿态 → 关键动作与触发 → 表情/回应 → 运镜与声音 → 结束状态”组织，动作、说话和反应可按剧情自然交织。首帧已有的造型、布景只作简短身份定位，把篇幅用于变化，不复制整份设定表。

- 对白逐字保留，每句只出现一次。标明固定说话人、语种、画内对白/画外同期声/旁白、实际语气和预计开口/结束时间，不能用“说出剧本里的台词”代替原文。
- 同一时段一名明确说话人；剧情需要接话时写明次序。听者可以有表情和动作，但不能跟着对口型或发出未写出的词句。当前项目曾出现无意义人声，故声音安排可合并写一句：只说列出的台词，不额外加词或背景人声。
- 动作音效贴着触发动作，持续底声放在声音概述中；同场保持相同底声方向和强度，不用声效盖住对白。默认不生成背景配乐。
- 运镜服从分镜。固定机位就是固定机位；移动时写出起动原因、方向和落幅，不自动加慢推、慢动作。切镜必须带来新的信息或观看关系。
- 每份 `prompts/Sxxx-h3.txt` 只含模型正文；文件路径、素材哈希、估时算式、参考来源及制作说明放在分镜或 `frames` 记录中。请求使用 `prompt_file`，脚本保存实际提交的全文和图片哈希。

## 让情感落到表演上

重要情绪节拍由人物此刻想达成的事驱动，写清“进入时的情绪/掩饰 → 什么刺激了他 → 态度如何变化 → 如何说或做 → 落在什么状态”。不是每人每镜都要完整转折；稳定态度也可以通过有目的的行动和语气表现。

- **可见表现**：选一两个当前景别看得清的信号，例如视线躲闪转为直视、下颌收紧、原本伸出的手停住、肩膀落下。远景用姿态和距离，近景用眼神及面部变化，不堆叠无法同时执行的细碎微表情。
- **可听表现**：把情绪写成音量、重音、气息和节奏变化，例如“前半句勉强镇定，关键事实落重音，后半句转为坚决”。语气不能永远是平缓、低声、无表情，也不能把强烈情绪一律等同于尖叫或哭腔。
- **有因果的反应**：先看到/听到刺激，再停手或转眼，再形成情绪与决定。短反应可参考 H3 的“刺激 → 一个明确情绪 → 两个可见信号 → 收势”写法，通常在约 1–1.5 秒内完成，并尽量与对白重叠；这是短反应的估计，不是每句之前都额外插入等待。
- **对手戏**：听者反应针对自己听懂的内容，不能与说话人同步复制表情。需要观众注意转移时，明确谁先动、谁随后回应。
- **音色与情绪分开**：`bible.json` 的性别/年龄段、基本音高、音质、口音和 `speaker_id` 跨请求复用；本镜音量、气息和情绪按剧情变化。文字约束能减少漂移，但当前首帧接口不提供跨请求的音色锁定。

可在现有分镜记录 `performance`：`trigger`、`entry_emotion`、`intention`、`visible_change`、`delivery`、`listener_response`、`exit_state`；只保留本镜有用项。最终正文把这些写成连贯表演，不向模型粘贴字段清单。

本次保持原有检查次数：不增加 ASR 对词、音色/口型检测或外部音频服务。提示词编写时保留原文属于创作职责，不能把它变成新的模型审查调用。来源、版本及许可证见 [provenance.md](provenance.md)。
