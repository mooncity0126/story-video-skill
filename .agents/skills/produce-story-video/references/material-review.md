# 本地工作台与生成前素材确认

用户要求在付费视频提交前检查已有素材。它是人工决定，不替代或增加原有模型检查次数。图片准备和报价可先完成；新的付费视频请求必须取得当前素材版本的用户确认。

## 入口与界面

以下操作在克隆的仓库根目录进行。

- 启动：运行 `Start-Workbench.ps1`，或用项目的 Python 执行 `scripts/workbench.py`。
- 地址：`http://127.0.0.1:8787/`；定位某个制作目录可用 `?project=<run目录名>`。
- 右上角「工作流设置」或 `?setup=1` 打开首次设置。用户选择并保存后可以新建影片。已有影片继续使用各自的快照。
- 界面提供项目切换、剧本、人物/场景、参考素材库、分镜卡片/列表、节奏条、最终提示词、成片播放与流程监视。
- 点击分镜检查实际提交首帧、选用的目标尾帧、对白、时长和完整提示词，选择“确认这段素材”或填写意见后选择“需要修改”。也可确认当前筛选的多个片段。
- 仅有定稿分镜的新项目，从“开始准备素材”进入同一队列，额度涵盖人物、场景、分镜图片和视频。工作台优先使用已有设定图，缺少时按人物准备定妆图、按场景准备固定布局的无人空场图。多位角色同框可将其参考合为一张身份参考板。新版 `workbench-assets.json` 的 `characters`、`scenes`、`shots` 分别按人物、场景和分镜编号索引。旧计划的 `reference` 和已有任务仍可续用。
- 工作台先读取分镜的依赖分析与 `dependencies.json`。连续镜头要等前镜视频检查采用、提取真实末帧后才编辑首帧。选择按依赖并行时，独立镜头可先准备和确认。逐镜串行时所有后镜均等待前镜实际尾帧。缺少依赖判断时，按播放顺序保守承接前镜。前镜换版后，后镜需用新来源准备相应素材，再按当前版本确认。
- 工作台将实际首帧与来源写入 `frames/<分镜ID>.json`。当前 AI 读取该图后，将最终 H3 正文写到 `prompts/<分镜ID>-h3.txt`，工作台按本片所选路线准备视频请求。直写确认原文，本地改写确认实际输出，在线优化确认送往服务端的原文。队列运行时，确认过的分镜有空位即提交。
- 页面顶部提供“开始生成”“暂停生成”和“继续生成”。开始后，队列提交已确认且依赖就绪的片段。暂停会阻止后续提交，已受理的任务继续同步。关闭或刷新网页保留队列状态，流程页每 5 秒更新进度。

## AI 与工作台的交接

1. 工作台的“制作输入”保存 `creative-brief.json`（创意、可选剧本、上限、画幅、风格、预算意向），并把 `workflow-inbox.json.status` 设为 `pending_planning`。它不会覆盖既有剧本、分镜、请求或预算授权。
2. 用户在对话里要求继续处理时，AI 先读待办及用户意见，更新真正的创作和请求文件。记录已应用的需求时间 `brief_saved_at`、处理说明和 `applied_at`，再把待办设为 `applied`；在项目锁内确认该需求未被用户另存新版本。不能在未完成规划时只修改待办状态。
3. 读取 `material-approvals.json.shots` 的修改意见，修正受影响片段，保留原确认记录以便显示“需重新确认”。素材准备好后让用户在工作台再次检查。
4. 用户确认由工作台写入：`actor: user`、`source: local_workbench`、`decision: approved/changes_requested`、`note`、`reviewed_at`、当前请求的 `fingerprint`。AI 不能代填此记录或代点击确认；自动测试只用独立测试素材。
5. 只有待办已处理、当前片段确认有效、用户已恢复该项目、预算已授权、依赖就绪并有空位时，才调用 `submit --execute`。确认素材本身不改变后面这些条件。

## 绑定规则

`media_tools.material_fingerprint` 绑定片段 ID、最终提交正文、实际图片内容哈希、请求时长、画幅、模型与参数、媒体服务地址。它不包含 API Key。每次读取工作台或提交时重新计算；与确认记录不同则显示 `outdated` 并阻止新视频提交。修改了文件内容但沿用文件名也会失效。

`submit_job` 在创建任务与调用云端前检查确认和待规划需求；未确认、要求修改、版本过期或存在待规划需求均不能提交。已存在任务仍按原幂等逻辑返回，不会重复生成；历史已生成片段无需补确认。报价、图片准备、下载、既定视频检查与合成沿用原规则。

`PAUSE_REQUESTED` 与已授权 `execution.budget_credits` 独立生效。“制作输入”内填写的是预算意向。用户在“授权并开始生成”窗口提交的额度才写入本项目的预算授权，已获得的聊天授权也可直接沿用。保留原生声音、4.1 字/秒估时、句尾余量和完整音轨合成。

## 运行与数据

前端与服务位于独立项目的 `workbench/`；依赖在同项目 Python 环境，锁定版本见 `workbench/requirements.txt`。只监听 `127.0.0.1`，不发布到外网。媒体接口仅提供制作目录内的图片/视频/音频，配置密钥不发送给浏览器。写操作要求本页会话标识并拒绝跨站来源。

新建项目会保存本地草稿，剧本、分镜、返工方案和候选内容判断由对话中的 AI 负责。网页控制的后台队列提交视频、同步结果、准备检查素材，并在候选检查通过后合成。续做时复用平台任务号和已有检查记录。
