# 从整场戏到可生成的分镜

用于工作流节点 3，并入节点 4 原有的一轮内容与时长检查。输入是按 [story-writing.md](story-writing.md) 写好的完整场景、人物与空间设定、用户片长约束，以及当前模型规格。下面的安排由 AI 在既有创作过程中完成，不新增服务、模型调用或制作节点。

## 先安排整场戏的事件

先沿整场戏排出关键事件：动作、说话、回应、信息出现和声音触发。标明哪些必须先后发生、哪些可自然重叠，以及场景进入和离开时的人物处境。此时先不切镜，避免按一句话一个镜头拆碎表演。

H3 普通中文对白以实读字数除以 4.1 为净说话时间，再计入必要的开口、呼吸、犹豫和换人；动作估时包含到达、接触、交接和完成。人物可边走边说，必须看清证据后才能回答的反应则不能提前。不要把可以同时发生的动作和对白逐项相加，也不要把所有事件都重叠以求更短。

整个故事的用时向关键选择、关系变化与结果倾斜。场景切换、重复铺垫和不改变信息的反应优先压缩；保留有必要的情绪体验。用户给出的片长上限不是必须填满的配额。

## 再决定为什么切镜

每个镜头用一句 `narrative_purpose` 说明观众新增知道或感受到什么，用 `cut_reason` 说明为何在这里改变观看位置。开始镜可记“进入场景”，结束镜可记“行动结果完成”。可用的理由包括：呈现新证据、看清行动的后果、关系主动权变化、建立必要空间、捕捉具有新意义的回应。

- 每个关键剧情动作只有一个主要呈现位置。前镜完成交接，后镜从交接后的状态开始，不再把递出、接住完整演一遍。`beat_ids` 用来追踪这类事件；一个事件跨镜时，写清前后分别完成哪一段。
- 不因出现新一句台词就切镜，也不因人物难过就自动特写。反应改变观众理解时可以独立成镜；已在同一画面看清的点头、微笑和凝视通常合并。
- 构图和运动服务需要看清的人、物与关系。需要同时看到两人和物品交接时，可使用稳定双人镜头；避免用多次无目的推拉和机位变化增加描述负担。
- 首帧是动作尚未发生的真实起始状态；目标尾帧是本镜自然到达的状态。不能在首帧提前交出物品、打开尚需打开的门或展示尚未揭示的答案。

## 将事件装入当前工具支持的片段

区分观看意义上的镜头与一次 API 生成的片段。既有 `shots` 每项仍对应一个独立生成片段和一个任务，但一个 H3 片段可以在提示词内包含少量事先规划的内部切镜。现有合成按顺序完整拼接片段，每个片段都要自行容纳完整句子和收尾；上一片段的尾帧只传视觉状态，不能维持下一次请求的连续发声。

1. 先选能够连续表演的动作与对白组合，按下节公式估时，再取本次接口支持的最短合法值。当前 H3 网关为 5–15 秒整数，若本片选用本地改写，取视频接口与改写器共同支持的时长。5–6 秒可以是计算结果，不是预先分配的统一配额。
2. 每镜记录预计对白起止时间，并满足 `最后一句结束时间 + 800–1000 毫秒句尾余量 <= 请求时长`。余量可包含自然收势；若有必须等对白结束才开始的关键动作，还需容纳该动作，不能把它塞进不足的余量。
3. 只需 1–3 秒的反应、证据展示或短句，优先并入相邻的同场表演单元；必要时在同一请求里安排有信息作用的内部切镜，采用 [minimax-h3.md](minimax-h3.md) 的 `[Shot N]` 与切点格式。不为每个小反应单独生成 5 秒，不为凑时长延长凝视或慢推，也不把不同场景和不相关事件硬塞进一段。
4. 片段过密时先去掉重复内容/次要动作，再安排可自然并行的表演；仍放不下才在完整句子和自然动作边界拆开，或在合法范围内延长。需要压缩台词时按授权修改剧本并同步记录，提示词环节不得擅自删改。不能用超快说话补救。
5. 同一片段中可安排画外对白、聆听者反应及声音跨内部切点。不能让一句话跨两个独立请求，也不假设合成会提供声音先入、延后跨段或音轨叠接；当前合成没有这类声音剪辑。
6. 每个生成片段最后一句后保留一次句尾余量；内部切点不重复添加整段余量。把各片段请求时长相加得到全片，再为模型实际多出的片尾预留空间。最终完整保留原生音轨，不靠裁音、加速或叠话补救超时。

所有时间是生成前估计，不是已测量的语音或强制对齐结果。当前 AI 将定稿的剧情、对白、声效、表演、起止状态和时间安排写入 H3 提示词，再按本片选择准备提交正文。

## 以对白为基准估时，再与动作时间合并

1. **计算实读长度。** 普通中文台词的标点、空格和标签不计字数；数字、日期、单位和缩写按实际念法计数，例如“120元”按“一百二十元”计 5 字。外语段落按对应口语单独估计，不把英文字符数除以 4.1。原台词保留原样，展开文本只用于估时。
2. **先算净说话时间。** 每句 `speech_seconds = spoken_chars / 4.1`。这是 H3 普通中文的起点；哽咽、艰难承认、笑中说话等确需变慢时，明确记录降低语速或增加哪处停顿及其理由，不把所有对白都默认放慢。
3. **只加必要间隔。** 普通直接对白起声约 0.3–0.5 秒；短意群/换人可从约 0.15–0.35 秒估起，关键犹豫按剧情另计。不要给每个逗号固定加大段停顿，也不要在每句前重复加起声和吸气；换人空隙已经承担的停顿不重复累加。情绪变化尽量发生在说话和行动中。
4. **排出实际时间线。** 逐句保存预计起止时刻，最后一句结束记作 `t_speech_end`。动作、反应与说话能同时发生就重叠；必须在某句之后发生的动作放在该句之后。把必要动作及自然收势全部结束的时刻记作 `t_action_end`。无对白片段只计算动作与收势，通常收势约 0.3–0.5 秒。
5. **向上取最短合法值。** 有对白时 `needed_seconds = max(t_speech_end + tail_margin, t_action_end)`，`tail_margin` 为 0.8–1 秒；无对白则取 `t_action_end`。对当前整数秒接口，`duration_seconds = max(5, ceil(needed_seconds))`；超过 15 秒必须重新组织或拆分，不能强行截为 15。说话结束后的听者反应/收势可自然使用尾部时间，不再重复加一次相同余量。

例如“这笔钱是我拿的，和她没有关系。”有 13 个实读汉字：净说话约 3.17 秒，加 0.3 秒起声、0.3 秒停顿和 0.9 秒句尾余量，约需 4.67 秒。若动作与说话重叠且在 4.5 秒前完成，申请 **5 秒**，而不是为“情绪戏”先分配 8–10 秒。若必须先走到桌前再开口，则把这段不重叠动作计入后重新计算。

`timing_reason` 记录实读字数/语速、必要停顿、动作重叠、最后一句结束、尾部余量及向上取整结果。可用 `timing` 对象保存这些数值；它是 AI 的规划记录，不增加估时模型、ASR 或检查步骤。不能把所有动作估为零来压缩，也不能用“cinematic”作为长停顿的理由。

## 保持空间、物品和人物知识连续

在 `bible.json` 的场景锚点中给出必要的固定布局，例如门、桌、窗口的相对位置，以及人物的工作侧和关键物品位置。复用场景不等于把全部布景描述塞进每镜，只带入当前画面需要的锚点。

区分世界中的固定位置和画面左右。改变机位时重新说明人物朝向、视线及对方位置。越轴或移动机位时交代空间过渡。每镜起止状态写明有关道具的数量、持有者和位置，以及人物的站位和已获知的信息。把依赖某次交接、移动或状态变化的镜头指向实际发生该变化的前镜，即使下一镜换成反打或近景也沿用这条依赖。按依赖并行时，明确独立的起始状态可共享人物与场景参考并行准备。逐镜串行时仍绑定前镜的实际尾帧。

## 保存到现有文件

新创作可在 `storyboard.draft.json` / `storyboard.json` 添加 `scene_plans`，每项包含：

| 字段 | 用途 |
|---|---|
| `scene_unit_id`、`scene_id` | 前者标记本次叙事场次，后者引用可复用的视觉场景；回到同一地点可以是新的叙事场次 |
| `purpose`、`entry_state`、`turn`、`exit_state` | 这场戏的作用、进入处境、关键变化、离开结果 |
| `beats` | 带 `beat_id` 的事件；记录动作/对白/声音事实、必要的先后关系或可重叠关系 |
| `planned_duration_ms` | 该场次各镜请求时长之和，含各镜句尾余量；不等同于实际生成时长 |

各生成片段在既有字段外可记 `scene_unit_id`、`beat_ids`、`narrative_purpose`、`cut_reason`、`timing` 和 `performance`。使用内部切镜时加 `internal_shots`，每项含 `shot_number`、`start_ms`、`camera`、`beat_ids`、`cut_reason`；从 0 开始，切点严格递增并小于片段时长。`timing_reason` 保存上述估时依据。这些是 AI 的创作记录，不是新增 API 参数或强制运行格式；旧项目仍可续做，不要求补齐旧文件或追加检查。

## 小例子：从拒绝独唱到接受合唱

排练室门外已传来报幕声。领唱小周握着麦克风，不肯上台；搭档阿岚也拿着麦克风。小周想退出，阿岚需要两人按时出场。这场戏的变化是阿岚提出“先一起唱”，小周因此愿意走向舞台，不靠劝说宣言直接消除恐惧。

可以合成一个 **6 秒**生成片段，包含两个有作用的观看位置：

| 内部镜头 | 时间 | 表演与声音 | 切镜作用 |
|---|---|---|---|
| Shot 1：门边双人中景 | 0–4.2 秒 | 小周 0.3–1.4 秒：“我怕忘词。”目光避开舞台。阿岚 1.6–3.2 秒：“第一句，我陪你。”说话同时举起自己的麦克风。小周肩膀稍松，3.4–4.2 秒：“好，一起。” | 同框看到阻力、办法及回应，避免一句一镜 |
| Shot 2：门口方向 | 4.2–6 秒 | 两人从门内迈向舞台，脚步声与行动同步，约 5.6 秒完成落幅；没有新台词 | 呈现决定的行动后果，而非再拍一次点头 |

三句共 13 个实读汉字，净说话约 3.17 秒，以上窗口包含少量停顿；最后一句结束于 4.2 秒，尾部至少 0.9 秒，必要行动到 5.6 秒，所以向上取 **6 秒**。若所选首帧不支持这样的走位，则重新估计动作，不照搬示例数字。也可保持一个双人镜头完成整段，不能为使用切镜功能而强行切镜。节点 4 原有的一轮检查同时处理事件、切镜、情绪因果与时间容纳，不增加声音检查。
